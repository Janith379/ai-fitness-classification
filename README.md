# AI-Based Fitness Classification

**Course:** IT2011 – Artificial Intelligence and Machine Learning
**Institution:** Sri Lanka Institute of Information Technology (SLIIT)
**Group:** Group 2

## Project Overview

This project explores the use of machine learning to classify fitness status using fitness-related data. It includes data preprocessing, exploratory data analysis, feature engineering, feature selection, feature scaling, and model evaluation.

## Project Structure

* `data/` – Dataset files, subject to sharing permissions.
* `notebooks/` – Original group notebook and individual preprocessing notebooks.
* `reports/` – Project report and submission documents.
* `results/` – Generated charts, preprocessing outputs, and model results.
* `requirements.txt` – Python dependencies.

## Individual Contributions

1. Missing value handling and duplicate removal
2. Binary encoding
3. Outlier handling
4. Categorical encoding
5. BMI feature engineering
6. Correlation analysis and feature selection
7. Feature scaling and standardization

## How to Run

1. Clone or download this repository.
2. Install the dependencies listed in `requirements.txt`.
3. Open the required Jupyter notebook or upload it to Google Colab.
4. Provide the required dataset.
5. Run the notebook cells in order.
